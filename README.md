# Между парами

Конкурсный прототип личного кабинета студента. Для демонстрации выбран понедельник, 23 ноября 2026 года. Все имена, расписания, оценки, заявки и учреждения в кабинете вымышлены.

Студент видит переносы и ближайшие занятия, проверяет оценки и сессию, получает объявления, подаёт заявку и отслеживает её статус. Для визита в деканат кабинет ищет время на пересечении расписания студента и часов приёма, учитывая длительность визита и запас до занятия.

## Локальный запуск

Требуется Node.js 24 или новее.

```sh
npm start
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Данные локального запуска сохраняются в `.local/campus.sqlite`. Для проверки предусмотрены два тестовых аккаунта и быстрый вход в отдельные демонстрационные сессии.

## Сборка

```sh
npm ci
npm run build
```

Сборка создаёт модуль Worker в `dist/server/index.js`. Серверное хранилище подключается через D1 с именем `DB`. Миграция базы находится в `drizzle/`.

## Структура

- `public/` — интерфейс и ресурсы браузера.
- `server/` — обработка запросов, правила подбора времени и вымышленные данные.
- `worker.mjs` — HTTP-обработчик для облака и для локальной среды.
- `local.mjs` — запуск на Node.js с SQLite.

Сервер сверяет введённый пароль с хэшем, выдаёт сессионную cookie HttpOnly и выбирает записи по владельцу из текущей сессии. Заявки и отметки о прочтении хранятся на сервере. Оформление документов и приём в деканате симулируются.

При регистрации посетитель придумывает логин и пароль и заполняет вымышленное ФИО, факультет, направление, курс и группу. Кабинет показывает заполненный профиль и пример учебного расписания. Заявки и уведомления привязаны к созданному аккаунту.

## Размещение

Vercel выдаёт интерфейс и принимает запросы к кабинету на одном домене. Функция в `api/` обращается к серверу с постоянной базой данных. Для входа на этой версии всегда нужен логин и пароль.

Для отдельного сервера с постоянным диском предусмотрены `Dockerfile` и конфигурация Amvera. База хранится в `/data`, порт приложения — `8080`. Внешний HTTPS обслуживает хостинг.
